# Initial reviewed curriculum coverage plan

This is an editorial planning target, not a statement that content is already authored or published. All imported or generated material must retain provenance and pass human review before publication.

## Launch pilot scope

| Track | Pilot lesson target | Question target | Required difficulty mix |
|---|---:|---:|---|
| Core Java / language fundamentals | 20 | 60 | Beginner, Novice, Professional |
| Collections, Streams and Generics | 15 | 45 | Beginner, Novice, Professional |
| JVM, memory and concurrency | 15 | 45 | Novice, Professional, Expert |
| Spring / Spring Boot | 20 | 60 | Beginner, Novice, Professional, Expert |
| SQL, persistence and JPA | 15 | 45 | Beginner, Novice, Professional |
| Microservices, messaging and distributed systems | 15 | 45 | Novice, Professional, Expert |
| System design and engineering leadership | 10 | 30 | Professional, Expert |

**Pilot target:** 110 lessons and 330 questions. Treat targets as acceptance criteria for the editorial pilot, not as published inventory.

## Editorial acceptance checklist

- [ ] Every lesson has a concise interview answer, detailed explanation, tested code/example and trade-offs.
- [ ] JDK, Spring, database or infrastructure version is stated where behavior is version-sensitive.
- [ ] Every question has a single unambiguous scoring contract and explanation.
- [ ] Code examples compile or have an explicitly documented pseudocode designation.
- [ ] Provenance and attribution are recorded; copied proprietary interview questions are excluded.
- [ ] Duplicate detection and reviewer sign-off are complete.
- [ ] Import validation passes and publication is a separate reviewer/admin action.

## Release tracking

Maintain a reviewed inventory by track, difficulty, question type, status and revision. Do not mark a target complete based on a JSON sample or draft count; count only approved, published revisions.
